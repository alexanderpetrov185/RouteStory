# RouteStory

Записывайте свои поездки с GPS и смотрите их в виде готового видео.

Приложение полностью локальное: нет аккаунтов, нет серверов, нет бэкенда. Единица данных — поездка (трек из точек + фото), хранится в Room на устройстве.

## Что умеет

- **Запись GPS-трека** — запись идёт в foreground-сервисе с уведомлением: пауза/продолжение/стоп, сворачивание и перезапуск приложения не обрывают поездку, случайно прерванная запись можно продолжить из черновика.
- **История поездок** — список всех записей, детальный экран со статистикой (дистанция, время, скорость) и фото.
- **Фото к поездке** — съёмка прямо во время движения, фото привязываются к точке маршрута и показываются на карте; на бесплатном тарифе до 10 фото на поездку.
- **Видео on-device** — поездка превращается в видео прямо на устройстве: спутниковая подложка, наклон камеры → наезд к старту → сопровождение маркера → отъезд на весь маршрут, вставка фото, музыка и звуки. Экспорт занимает минуты и работает без бэкенда.
- **Pro** — снимает водяной знак, убирает лимит фото на поездку (в видео используется до 12 вставок) и открывает видео 1280×720 вместо 736×414.

Спутниковые тайлы и растровые тайлы подложки подгружаются с публичных картографических сервисов — **нужен интернет**, но только для показа карты и экспорта видео. Сами данные поездок никуда не отправляются.

## Технически

- Kotlin, Jetpack Compose (Material 3), Hilt, Room, MVVM + Clean Architecture.
- **minSdk 29** (Android 9+), targetSdk 35.
- **Offline-first:** поездка целиком живёт в локальной базе, сетевых вызовов для записи и просмотра истории нет, backend отсутствует.
- Карта: живая карта — OSM-тайлы на canvas-рендере (`OsmTileLayer`; MapLibre остаётся в коде, но на тестовом устройстве давал пустой экран, поэтому отключён `FORCE_OSM_CANVAS`), подложка видео — спутник Esri World Imagery. Без интернета карта не подгрузится, но запись и просмотр статистики работают.
- Видео кодируется на устройстве (MediaCodec/MediaMuxer), без облака.

## Установка

Готовый APK — в разделе [Releases](../../releases), файл `RouteStory-0.0.1-debug.apk`.
Это **debug-сборка** (release-сборка пока без подписи), поэтому при первом запуске Android попросит разрешить установку из неизвестных источников.

## Сборка из исходников

```bash
git clone https://github.com/alexanderpetrov185/RouteStory.git
cd RouteStory
./gradlew :app:assembleDebug      # APK: app/build/outputs/apk/debug/app-debug.apk
./gradlew :app:testDebugUnitTest
```

## Про построение маршрутов

**Построение маршрутов (route builder) в этой версии отключено и не входит в UI.** Код полностью сохранён в ветке [`feature/route-builder`](../../tree/feature/route-builder) и будет возвращён отдельно.

В текущей версии 0.0.1 недоступны: построение маршрутов, список сохранённых маршрутов, синий слой плана на экране записи и «сохранить поездку как маршрут».
